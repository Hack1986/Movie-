123HDC Web App (PWA)

วิธีทดลอง:
1) แตกไฟล์ ZIP
2) อัปโหลดไฟล์ทั้งหมดขึ้นโฮสติ้งที่รองรับ HTTPS เช่น Netlify หรือ GitHub Pages
3) เปิด URL ที่ได้บน Chrome Android
4) เลือกเมนู 'ติดตั้งแอป' หรือ 'เพิ่มไปยังหน้าจอหลัก'

หมายเหตุ:
- เว็บแอปนี้เป็น PWA shell สำหรับเข้าถึง https://www.123-hdc.com/
- เว็บไซต์ต้นทางอาจไม่อนุญาตให้ฝังใน iframe; หากเกิดกรณีนี้ให้กด 'เปิดเว็บไซต์ 123HDC' เพื่อเปิดเว็บโดยตรง
- การติดตั้ง PWA ต้องให้บริการผ่าน HTTPS หรือ localhost
- ไม่ได้ดึง/จัดเก็บ/แจกจ่ายวิดีโอหรือเนื้อหาจากเว็บไซต์ต้นทาง
